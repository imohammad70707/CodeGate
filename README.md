# 🔐 CodeGate

**CodeGate** یک ربات تلگرامی برای ساده‌سازی و مدیریت فرآیند درخواست کد ورود برای حساب‌های متعلق به کاربر است.

این پروژه با دریافت اطلاعات موردنیاز از کاربر، فرآیند درخواست کد ورود را مدیریت کرده و وضعیت مراحل انجام‌شده را به‌صورت خودکار در محیط ربات نمایش می‌دهد.

> ⚠️ این ابزار صرفاً باید برای حساب‌هایی استفاده شود که متعلق به خود کاربر هستند یا کاربر مجوز مدیریت آن‌ها را دارد.

## 📋 قابلیت‌ها

* 🤖 اتصال به ربات تلگرام
* 📱 دریافت شماره تلفن کاربر
* 🔐 مدیریت فرآیند درخواست کد ورود
* 📊 نمایش وضعیت درخواست در محیط ربات
* ⚡ پاسخ‌دهی خودکار به دستورات کاربران
* 🔄 مدیریت مراحل فرآیند به‌صورت خودکار

## ⚙️ نحوه عملکرد

```text
کاربر
  ↓
ارسال دستور
  ↓
دریافت شماره تلفن
  ↓
شروع فرآیند درخواست کد ورود
  ↓
پردازش درخواست
  ↓
نمایش وضعیت در ربات
```

## 📝 توضیحات

CodeGate با هدف ساده‌تر کردن فرآیند درخواست و مدیریت کد ورود طراحی شده است.

کاربر اطلاعات لازم را از طریق ربات ارائه می‌کند و سیستم مراحل موردنیاز را به‌صورت خودکار مدیریت کرده و وضعیت فرآیند را در محیط ربات نمایش می‌دهد.

ساختار پروژه به‌گونه‌ای طراحی شده که قابلیت توسعه و اضافه‌کردن امکانات جدید به آن وجود داشته باشد.

## 🛠️ تکنولوژی

```text
Language: Python
Platform: Telegram Bot
```

کتابخانه‌ها و وابستگی‌های موردنیاز پروژه در فایل `requirements.txt` قرار دارند.

## 🚀 نصب و اجرا

ابتدا Repository را Clone کنید:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

سپس وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

توکن ربات را در محل مناسب تنظیم کرده و پروژه را اجرا کنید:

```bash
python main.py
```

> نام فایل اجرای پروژه را در صورت متفاوت بودن با `main.py` تغییر دهید.
